01 BACKEND

BACKEND / REST APIS / DATA INTEGRITY

MediSync Pro

SCALABLE BACKEND FOR APPOINTMENTS & MEDICAL RECORDS

A scalable backend system with 40+ RESTful APIs built using Spring Boot, Spring Data JPA, and MySQL, enabling structured CRUD operations across multiple modules.

It enforces business rules such as preventing duplicate same-day appointments and workflow-based medical record creation, with API validation, exception handling, and end-to-end workflow testing in Postman.

02 FULL STACK

FULL STACK / SECURITY / E-COMMERCE

Quick Mart

SECURE FULL-STACK E-COMMERCE APPLICATION

A scalable full-stack application built with Spring Boot, Spring Data JPA, MySQL, and React.js, with secure RESTful APIs across authentication, product, category, cart, order, and user management modules.

It uses JWT-based authentication and role-based authorization with Spring Security, and integrates Cloudinary for product image management, with REST APIs validated through Postman.

JWT + ROLES

03 AI / FULL STACK

AI / RAG / ENTERPRISE

Nexora AI

AI-POWERED ENTERPRISE PLATFORM

An AI-powered enterprise platform built with Spring Boot, React.js, PostgreSQL, and LangChain4j, using Large Language Models to automate document analysis, intelligent search, and conversational assistance.

It implements Retrieval-Augmented Generation (RAG), combining vector embeddings with LLMs for context-aware responses from uploaded PDFs and business documents, with secure JWT authentication, role-based authorization, and real-time notifications.
